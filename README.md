# Blazing Bamboo (Unofficial)

Fiery bamboo from crimson forests, blaze fuel and rods, lava rafts, and wood and stone building sets. Original gameplay and artwork by PaddedShaman; modern ports by Oculifelis.

MIT licensed. See LICENSE.txt for the original copyright and terms.

This branch targets Minecraft 1.21.1 on NeoForge using a shared MultiLoader source tree.

Optional Thaumaturge support adds aspects and crucible fuel values only.

Build with Java 21 and the included Gradle wrapper. Run `gradlew.bat :neoforge:build --no-daemon --max-workers=2`.
